# Common Resources

This directory contains reusable components, patterns, and utilities that can be used across multiple domains.

## Structure

- **shared-components** - Reusable BPMN subprocesses, service tasks, and components that can be imported into domain-specific workflows
- **patterns** - Common workflow patterns (e.g., approval patterns, notification patterns, error handling patterns)
- **utilities** - Helper scripts, validation tools, or transformation utilities for working with BPMN templates

## Usage

These resources are designed to be referenced and reused across different domain templates to maintain consistency and reduce duplication.
