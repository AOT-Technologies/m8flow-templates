# Domain Templates

This directory contains BPMN workflow templates organized by business domain.

Each domain folder contains workflow templates specific to that industry or business area.

## Available Domains

- **finance** - Financial processes, accounting, banking workflows
- **healthcare** - Medical processes, patient care, clinical workflows
- **manufacturing** - Production processes, quality control, assembly workflows
- **it-technology** - Software development, IT operations, DevOps workflows
- **human-resources** - Recruitment, onboarding, employee management workflows
- **sales-marketing** - Sales processes, marketing campaigns, lead management
- **supply-chain** - Procurement, inventory management, distribution workflows
- **customer-service** - Support tickets, customer onboarding, complaint handling
- **legal-compliance** - Legal processes, compliance checks, audit workflows
- **education** - Academic processes, student management, course workflows
- **real-estate** - Property management, leasing, sales workflows
- **retail** - Point of sale, inventory, customer experience workflows
- **logistics** - Shipping, warehousing, transportation workflows
- **insurance** - Claims processing, underwriting, policy management
- **telecommunications** - Network operations, service provisioning, maintenance

## Adding New Templates

1. Navigate to the appropriate domain folder
2. Add your BPMN template file (`.bpmn` or `.bpmn20.xml`)
3. Include a descriptive filename that indicates the workflow purpose
4. Optionally add documentation in a README within the domain folder
